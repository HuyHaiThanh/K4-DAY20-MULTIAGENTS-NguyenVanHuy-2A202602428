---
name: data-cleaning-and-normalization
description: Use this skill when preparing raw data for analysis by normalizing fields, parsing dates, removing duplicates, and handling missing or invalid values.
---
- Normalize categorical fields to canonical forms (e.g., region names).
- Parse dates from multiple formats and convert to a consistent timezone.
- Remove duplicate records based on unique identifiers, keeping the first occurrence.
- Identify and handle missing or invalid data values appropriately.
